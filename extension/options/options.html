This extension reads the page. Your Python container does everything else.

Defaults

Categories

Nothing to set here. Every note is filed automatically: the category comes from the rule matching the site you clipped, and the subcategory from the category the page publishes about itself — the one the author filed it under. A site that declares nothing leaves the field blank rather than guessing.

Change how a site is filed in server/config/config.yaml, next to its other rules.

Where the rest lives

Templates, file names, categories and per-site routing are not configured here — they're in the container, so you can edit them without reloading the extension.

server/config/config.yaml
The template, tags and category each domain gets
server/config/templates/
Drop a .md.j2 file here to override a built-in template
.env
Vault path, port, token, UID/GID

Config changes take effect on the next clip. No restart.
